## 👋 Bienvenue chez Cornavo

**Cornavo est un collectif d'ingénierie logicielle spécialisé dans l'intégration de l'IA.** Notre ambition : transformer des besoins métier en solutions concrètes, robustes et maintenables — de l'idée à la production.

Nous réunissons des expertises complémentaires en **frontend, backend, architecture et infrastructure**. Nous privilégions l'IA appliquée à de vrais problèmes, avec une attention particulière portée à la qualité, à la sécurité et à l'expérience utilisateur.

## 🧭 Nos domaines d'expertise

| Domaine | Ce qui nous intéresse |
| --- | --- |
| **AI Engineering** | Intégration de LLM, RAG, agents et outils IA dans les applications et les workflows. |
| **Software Engineering** | Applications modernes, API, Angular, Java / Spring Boot et architecture logicielle. |
| **Cloud & DevOps** | Conteneurisation, CI/CD, AWS, infrastructure as code et observabilité. |
| **Quality & Accessibility** | Tests automatisés, accessibilité numérique et maîtrise des régressions. |

## 🛠️ Notre approche

**Explore → Build → Validate → Share**

1. **Explore** — Comprendre le problème et identifier où l'IA apporte une valeur réelle.
2. **Build** — Construire un prototype ou une intégration simple et reproductible.
3. **Validate** — Mesurer le résultat, tester la fiabilité et documenter les limites.
4. **Share** — Publier du code, des démonstrations et des retours d'expérience utiles.

Nous partageons nos apprentissages en open source, au travers de projets techniques, de contenus pédagogiques et de cas d'usage proches du terrain.

## 🚀 Projets open source

### ♿ Le Cliquet d'accessibilité — *en préparation*

Notre premier projet explore un problème fréquent dans les applications existantes : **introduire des contrôles d'accessibilité en CI/CD sans bloquer les équipes sur toute la dette historique**.

- **`a11y-cliquet`** — CLI et GitHub Action utilisant une baseline pour identifier les nouvelles régressions détectables automatiquement.
- **`a11y-ci-starter`** — Application Angular de démonstration avec Playwright, axe-core et GitHub Actions.

> Ces projets sont en cours de préparation. Les contrôles automatiques ne remplacent pas un audit complet de conformité RGAA/WCAG.
